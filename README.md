# Desafío Web: Fibonacci y Números Primos en la Vida Real

## Descripción del Proyecto

Este proyecto consiste en una **página web interactiva** desarrollada con **HTML, CSS y JavaScript**, donde se aplica la **sucesión de Fibonacci** y la **verificación de números primos** para resolver **tres problemas del mundo real**:

| Proyecto | Área de Aplicación | Descripción |
|----------|-------------------|-------------|
| **Ciberseguridad** | Seguridad Informática | Validación de códigos de acceso y generación de tokens criptográficos basados en números primos. |
| **Diseño Natural** | Biología / Botánica | Simulación del crecimiento floral y distribución de pétalos usando la serie de Fibonacci (niveles 1 al 20). |
| **Plan de Ahorro** | Finanzas Personales | Simulación de ahorro progresivo donde cada depósito sigue la serie Fibonacci, identificando los depósitos que son números primos. |

## Problemas del Mundo Real Resueltos

### 1. Ciberseguridad (Números Primos)
Las filtraciones de datos y ataques de fuerza bruta rompen millones de contraseñas débiles al día. La infraestructura bancaria y militar moderna utiliza criptografía RSA, un sistema que resguarda datos multiplicando **números primos gigantes**. Este proyecto verifica si un número es primo para determinar si puede servir como clave segura.

### 2. Diseño Natural (Sucesión de Fibonacci)
Las plantas necesitan distribuir hojas y pétalos para maximizar la luz solar. La evolución optimizó este recurso usando la **Sucesión de Fibonacci**, logrando un empaquetamiento perfecto donde cada elemento crece en un ángulo dorado constante. El proyecto simula este crecimiento desde el nivel 1 hasta el nivel seleccionado (máximo 20).

### 3. Plan de Ahorro (Fibonacci + Números Primos)
Un esquema de progresión orgánica basado en **Fibonacci** disminuye la fricción inicial permitiendo ahorrar montos pequeños que crecen de manera escalonada. Cada depósito mensual es analizado para determinar si es **número primo**, catalogándolo como un "Hito de Ahorro Blindado".

## Objetivos del Proyecto

- Aplicar la **sucesión de Fibonacci** en casos reales (finanzas, biología, seguridad).
- Implementar un algoritmo estricto de **verificación de números primos**.
- Utilizar **formularios HTML** interactivos para la captura de datos.
- Mostrar resultados dinámicamente controlando el **DOM con JavaScript nativo**.
- Diseñar una interfaz **moderna y responsiva** adaptable a cualquier pantalla.
- Organizar el proyecto manteniendo la **separación clara** de arquitecturas (HTML, CSS y JS).
