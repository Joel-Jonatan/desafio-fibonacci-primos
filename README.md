# Desafío Web: Fibonacci y Números Primos en la Vida Real

## Descripción del Proyecto
Este proyecto consiste en una página web interactiva desarrollada con HTML, CSS y JavaScript, donde se aplica la sucesión de Fibonacci y la verificación de números primos para resolver un problema relacionado con el mundo real: **un plan de ahorro progresivo**.

El sistema simula un esquema financiero donde una persona incrementa sus depósitos mensuales siguiendo la serie de Fibonacci. Adicionalmente, el programa analiza matemáticamente cuáles de esos depósitos corresponden a números primos, inyectando los resultados de manera dinámica y aplicando un diseño visual responsivo de última generación.

## Problema del Mundo Real
En este proyecto se utiliza la serie de Fibonacci para simular un sistema de ahorro progresivo, donde cada mes el depósito aumenta siguiendo el patrón:
`1, 1, 2, 3, 5, 8, 13...`

Cada depósito es analizado minuciosamente mediante un algoritmo de validación para determinar si corresponde a un número primo, permitiendo al usuario ingresar datos mediante formularios y evaluar su comportamiento financiero directamente en pantalla.

## Objetivos del Proyecto
* Aplicar la sucesión de Fibonacci en un caso real de simulación financiera.
* Implementar un algoritmo estricto de verificación de números primos.
* Utilizar formularios HTML interactivos para la captura limpia de datos.
* Mostrar resultados dinámicamente controlando el DOM con JavaScript nativo.
* Diseñar una interfaz moderna y responsiva adaptable a cualquier pantalla.
* Organizar el proyecto manteniendo la separación limpia de arquitecturas (HTML, CSS y JS).

* **CSS3 Premium:** Estilos basados en Glassmorphism (efecto cristal), fondos dinámicos animados (`@keyframes`) y maquetación responsiva avanzada.
